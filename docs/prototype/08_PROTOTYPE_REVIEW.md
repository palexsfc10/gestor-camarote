# Prototype 08 — Revisão do Protótipo

## Veredicto

**Pronto para apresentação comercial** como protótipo visual navegável, com ressalvas.

## O que funciona bem

- Narrativa cliente → casa → mapa → preparação  
- Honestidade de status (solicitação ≠ confirmação)  
- Nav admin anti-ERP (5 itens + Gestão)  
- Dialogs de consequências  
- Estado local coerente ao confirmar/cancelar  

## Limitações

- Sem persistência (F5 perde mutações da sessão)  
- Sem backend / multi-tenant real  
- C07 já pré-reservado (atalho demo Mariana)  
- Imagens são gradients, não fotos reais  
- Playwright pode exigir `npx playwright install`
